Programs | Utilities

Here we have some small programs and utilities I've made in hopes of making life a little easier when working with random source port engines, etc.

Hopefully you'll find them useful too!

 

Legacy Launcher 2
The old Doom Legacy Launcher 1.x lost its way some time back in the XP days and later became somewhat incompatible when trying to load PWADs and such. Because of this, and noticing the recent development activity with the Doom Legacy engine, I decided the launcher needed a bit of attention. So I made a new one. I give you: Doom Legacy Launcher 2! A modern Windows launcher built for the Doom Legacy source engine, designed to make setting up, hosting, and joining games as simple as possible. Doom Legacy Launcher 2 handles engine setup, IWAD/PWAD management, network hosting and joining, IWAD/addon integrity verification, and more, all wrapped in an interface inspired by the Doom Legacy website theme.

Want more info?

Managed-Doom Launcher
A simple launcher for the Managed-Doom source engine. The Addons tab area of the launcher has the ability to remember previously loaded PWAD and Deh locations, so you can quickly select what you want to load from History. Also supports drag 'n' drop.

 

Visit the:

Managed-Doom Launcher site

Quick Launcher
Quick Launcher is just what it says it is. No bells, no whistles. But a really quick way to load or test your map or mod with just about any source engine. Because it doesn't have any combo box selections and such, it requires that the user already knows which command parameters to type in the textbox at the bottom of the utility, e.g. +map or -warp, depending on the source engine loaded.

 

Download:

quick_launcher.zip

File List Exporter
File List Exporter is a really small utility to simply export the file names in a given directory to a .txt file called file_list.txt. This can come in handy if you have, for example, a bunch of images and you want to make an animation script for a project, where the outputted text file will end up with a list of all the image names, so you won't need to type them all out manually.
